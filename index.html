Your script

This screen — and any Sound/Link/Timer blocks on it — only runs while it is the telemetry screen shown on your radio. Set it as your default/home screen if alarms should always be active.

Note: the file saves as .txt (sandbox restriction). Rename it to .lua before copying it to your SD card.

Installation guide
  1. Rename the downloaded file to (if it was saved as .txt).
  2. Copy it to your SD card at /SCRIPTS/TELEMETRY/.
  3. Put sound files as .wav (16-bit PCM) under /SOUNDS/, using the same names as in the script.
  4. On your radio: Screens → add a telemetry screen → type "Script" → pick this file.
  5. Test on the ground with no motor/propellers before flying.

How to build your script

  1. Tap blocks on the left to add them to your script, one under another — display blocks like Text or Gauge, and action blocks like Sound Alarm.
  2. Open a block in the middle column to set its properties: source, thresholds, sounds, text.
  3. Reorder blocks with the arrows or by dragging the handle — the order on screen matches the order in the list.
  4. Watch the mock LCD and the Lua code update live on the right.
  5. Copy the code or download it, rename to .lua, and copy it to /SCRIPTS/TELEMETRY/ on your SD card.
  6. Assign it as a telemetry screen on your radio, test on the ground, then fly.
